TikTok Integration

How Luminare Gallery uses TikTok

This page describes how Luminare Gallery integrates with TikTok’s developer platform for promotional content sharing.

1. Purpose of the Integration

Luminare Gallery uses TikTok Login Kit to authenticate its own TikTok creator account. This allows the studio to post promotional video content about its wall art products directly to its own TikTok profile.

The integration uses TikTok’s Content Posting API to upload videos as drafts to the Luminare Gallery TikTok account. All posts are reviewed and published manually by Luminare Gallery.

2. What We Do

  • Authenticate the Luminare Gallery TikTok creator account using Login Kit (OAuth 2.0).
  • Upload promotional video content about Luminare Gallery wall art prints as drafts via the Content Posting API.
  • Review and manually publish drafts from within the TikTok app or Creator Studio.

3. What We Do Not Do

  • We do not access, collect, or store any data from third-party TikTok users.
  • We do not perform scraping, automated mass posting, or spam.
  • We do not post on behalf of any third party.
  • We do not use the integration for any purpose other than publishing Luminare Gallery’s own promotional content.
  • We do not sell, share, or monetise any data obtained through TikTok APIs.

4. Data Handling

The only data obtained through the TikTok API is the OAuth access token required to authenticate the Luminare Gallery account. This token is stored securely, used solely for uploading content drafts, and is never shared with any third party.

No personal data belonging to TikTok users is collected, processed, or retained.

5. Redirect URI

This page (https://luminaregallery.com/tiktok-integration.html) is registered as the OAuth redirect URI for the Luminare Gallery TikTok developer application. It serves only as the callback endpoint during the authorisation flow and does not collect any user information.
